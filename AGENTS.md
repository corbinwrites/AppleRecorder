# AGENTS.md: Apple Recorder

Native macOS meeting recorder. Spec: `docs/BUILD-GUIDE.md` (do NOT read it whole). Work one step per session from `docs/tasks/<STEP>.md`.

## Loop
1. Open `PROGRESS.md`. Take the first step that is not `done`.
2. Read `docs/tasks/<STEP>.md`. It holds the rules and the spec sections you need.
3. Run its `VERIFY:` command and watch it fail. Write code until it passes. Fast loop: `swift test --filter <Suite>`.
4. The task's `VERIFY:` line replaces "run `make test`" in the guide's rule 2. Other packages may still be red; that is expected.
5. Update `PROGRESS.md`. Commit `<STEP>: <what>`. Stop. Do not start the next step.

## Hard rules
- **Never edit, rename, delete, or skip a spec test.** Files under `Packages/*/Tests` and `App/UITests` at tag `spec-v1` are frozen (`scripts/protect-tests.sh`). New test files are allowed. A test that looks wrong goes in `BLOCKERS.md`. Stop.
- **Never guess an Apple or WhisperKit API.** Run `scripts/apple-api.sh <Symbol>`, read `docs/reference/sdk/`, read `.build/checkouts/`. Record what you confirm in `docs/API-NOTES.md`. Not found: `BLOCKERS.md`. Stop.
- Use the exact names, paths, and signatures in the task file. No renaming, no reorganizing, no extras.
- Only dependency: `argmax-oss-swift` (product `WhisperKit`). No network at runtime except the model download. No telemetry.
- Swift 6, strict concurrency. No `!` or `try!` outside tests. No `print` outside `SelfTest/` and `scripts/`; use `Logger`.
- Realtime audio code lives only in `RealtimeCallback.swift`. `scripts/check-realtime.sh` must pass.
- Never delete user data (notes, audio, transcripts) except on an explicit user action.
- Hardware, permissions, Discord, Apple Intelligence: do the software part, write the test, mark the step `NEEDS HUMAN`. **Never fake a hardware result.**
- Never edit `docs/BUILD-GUIDE.md`, `docs/research/*`, or `docs/tasks/*` (generated by `make tasks`).
- Never commit secrets (`*.p12`, `release-key.pem`, `.env`). Never force-push. Never rewrite pushed history.
- Same failure 3 times: write `BLOCKERS.md`. Stop. Ask no questions. Decide from the task file, or stop.

## Stubs
Unimplemented functions throw `TODO.notImplemented` or call `fatalError("TODO")`. A `fatalError` crashes the whole test process, so always filter by suite while you work.
